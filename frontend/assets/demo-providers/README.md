# Temporary Home Services demo assets

These local SVGs are replaceable UI placeholders for the Home Services subcategory page. The service illustrations are not photos, and the generic provider avatar does not represent a real person or provider.

The UI prefers a service image returned by the existing API. When a listing has no image, it uses `demo-provider-placeholder.svg`. The subcategory photo card uses the matching `demo-*.svg` illustration, while the compact promotional strip uses `home-services-promo.svg`.

Replace these files with approved local images or delete the placeholders later. Update the image paths in `frontend/category-page.js` if filenames change. Do not overwrite or replace provider-uploaded images with these demo assets.
